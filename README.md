# Pharmacy Inventory Management System

## Overview

This is a simple console-based pharmacy inventory management system developed using Java.

The project was created to demonstrate core Java programming and object-oriented programming concepts.

## Features

- Add medicine
- View all medicines
- Search medicine by name
- Update medicine quantity
- Delete medicine
- Exit the program

## Java Concepts Used

- Classes and objects
- Constructors
- ArrayList
- Scanner
- Loops
- If/else statements
- Methods
- Basic CRUD operations
